# 漫游手记 · Cyrene's Journal

一个把收藏夹做成日记本的导航站 —— **https://xilian-nav.pages.dev**

![封面](assets/xilian-wallpaper.jpg)

## 为什么会有这个站

被昔涟的身份和那段故事打动。看完那几天，有点缓不过来。

厨上一个角色之后，总想给她做点什么：剪视频、画图、写文……可惜这三样我都不太行。

**唯一能干的是写代码（指使ai）。**

于是去年 12 月某天半夜，这个玩意就冒出来了：一个导航站，外壳做成她的日记本。

## 里面有什么

- 77 个站点、9 个分类，按"现在就会打开"挑的，不是把收藏夹倒进来
- 搜索（Ctrl / ⌘ + K）、收藏、常用置顶、随机"换一站"
- 明暗主题、紧凑视图、弹窗磨砂玻璃开关
- 原画沉浸查看：往下滚封面的时候，她还停在那儿

## 技术

原生 ES Module，没有框架，也没有构建依赖（只有一个把 src 变成发布目录的小脚本）。

- 样式拆成 8 个 CSS 模块
- 站点数据在 data/sites.js，加一条就是一行
- 字体、壁纸全部本地化，不依赖 CDN
- 纯静态：没有后端、不做统计，收藏和设置只存在你自己的浏览器里
- 页脚署名删掉会被 JS 补回来（不是防你，是防随手复制时丢了）

## 说三件事

1. 页脚有署名。想拿走改随便，但那行别删——那是我唯一还留着的东西。
2. 旧版有磨砂玻璃，这一版重做成纸质感时弄丢了，现在以开关的形式回来了（bushi）。
3. 这个仓库里放的是**发布产物**（直接能跑的那种），开发源码和测试在我本地。

## 许可

随便看、随便抄，署名别删就行。
